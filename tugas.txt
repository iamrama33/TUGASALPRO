1.Jelaskan dengan bahasa Anda sendiri apa perbedaan antara compiler dan interpreter.
jawab;Compiler menerjemahkan seluruh kode program sekaligus di awal. Hasil terjemahan ini disimpan dalam bentuk file baru (seperti file .exe). Proses eksekusinya sangat cepat karena komputer tinggal menjalankan file jadi tersebut, tetapi proses pencarian bug (kesalahan) cenderung lebih lama karena semua error ditampilkan sekaligus setelah proses kompilasi selesai.Interpreter menerjemahkan kode program baris demi baris secara langsung saat program dijalankan. Tidak ada file eksekusi terpisah yang dihasilkan. Proses ini membuat pencarian bug lebih mudah karena program akan langsung berhenti tepat di baris yang salah, namun kecepatan eksekusinya lebih lambat dibandingkan hasil kompilasi.

3.Mengapa program C selalu membutuhkan fungsi main()? Apa yang terjadi jika fungsi ini tidak ada? 
jawab;Program C selalu membutuhkan fungsi main() karena fungsi ini merupakan titik awal (entri utama) eksekusi program. Ketika program dijalankan, sistem operasi akan langsung mencari dan mengeksekusi instruksi yang ada di dalam fungsi main() terlebih dahulu.Jika fungsi main() tidak ada, program tidak akan bisa dikompilasi atau dijalankan. Compiler akan mengeluarkan error (biasanya berupa linker error seperti "undefined reference to main"), karena sistem tidak tahu dari baris mana program harus mulai membaca instruksi.

4. Menurut Anda, mengapa penamaan variabel yang jelas (deskriptif) penting dalam pemrograman, khususnya untuk program yang berkaitan dengan pengukuran teknik?
jawab;Dalam program pengukuran teknik, variabel merepresentasikan parameter fisik yang nyata di dunia nyata. Penamaan yang jelas sangat penting karena beberapa alasan berikut:Mencegah Salah Interpretasi Satuan dan Parameter: Menggunakan nama seperti tegangan_input_volt jauh lebih aman daripada sekadar huruf v. Ini memastikan tidak ada ketertukaran antara tegangan input, tegangan output, atau variabel kecepatan (velocity).Mempermudah Kalibrasi dan Audit Kode: Rumus teknik sering kali kompleks. Jika variabel diberi nama deskriptif (misal: arus_maksimal_ampere), teknisi atau insinyur lain dapat dengan mudah memvalidasi apakah rumus matematis yang diimplementasikan dalam kode sudah sesuai dengan teori sirkuit atau standar keselamatan fisik.
